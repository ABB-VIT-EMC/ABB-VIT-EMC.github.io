ABB SpA Vittuone Laboraytory Software Documentation
====================================================

This site collects the published documentation for ABB VIT EMC software.

The content may include a philosophy, a getting-started guide, a user guide, and an API. 
All these projects are developed at the EMC Laboratory of ABB SpA, Viale dell’Industria 18, Vittuone, Milan, Lombardy, Italy.

The team includes

* Thanapong Chuangyanyong
* Camilla Sergiano
* Lorenzo Strechelli
* Stefano Petrillo

This site does not include `cartamodello-code <https://github.com/ABB-VIT-EMC/cartamodello-code>`_ VSCode extension, since ``README`` suffices.
